# HR Analytics Dashboard: Employee Insights

## 📌 Project Overview
This project analyzes employee data to uncover key insights about workforce trends, employee performance, and attrition. The goal is to help HR teams make data-driven decisions to improve employee retention and organizational efficiency.

---

## 🎯 Objectives
- Analyze employee distribution across departments
- Identify patterns in employee attrition
- Evaluate factors affecting employee performance
- Provide actionable insights for HR decision-making

---

## 🛠️ Tools Used
- Power BI / Tableau
- Excel (Data Cleaning)
- Data Visualization Techniques

---

## 🔍 Data Cleaning Process
- Removed duplicate records
- Handled missing values
- Standardized column formats
- Verified data consistency

---

## 📊 Key Insights
- High attrition rate observed in specific departments
- Employees with lower job satisfaction were more likely to leave
- Certain roles showed higher turnover trends
- Experience level influenced employee retention


## 💡 Recommendations
- Improve employee engagement in high-attrition departments
- Introduce retention strategies for at-risk employees
- Monitor job satisfaction metrics regularly
- Provide targeted support for new employees
